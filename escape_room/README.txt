密室逃脫題目發想器 v1.0
========================

【使用說明】

1. 雙擊「開啟密室題目發想器.bat」啟動程式
   （或直接執行 python escape_room_gui.py）

2. 選擇模式：
   - 單一謎題：生成一道謎題
   - 完整遊戲：生成故事背景 + 3～5 個串接關卡

3. 選擇主題：
   - 課文：從下拉選單選擇預設課文
   - 自訂：輸入任意主題名稱

4. 選擇謎題類型（至少選一種）：
   字謎、數字謎、密碼謎、邏輯推理、圖像描述

5. 點選「開始發想」，結果會顯示在下方預覽區

6. 可勾選「顯示提示」或「顯示答案」

7. 點選「匯出 Word」儲存成 .docx 文件

【注意事項】

- 首次使用前請安裝相依套件：
  在命令提示字元輸入：pip install python-docx

- 每次按「開始發想」或「重新發想」都會隨機生成不同題目

- Word 文件中的答案欄位預設為「請教師填入正確答案」，
  請根據實際課文內容自行填寫

【套件需求】

- Python 3.8 以上
- python-docx（pip install python-docx）
- tkinter（Python 內建，無需另外安裝）
