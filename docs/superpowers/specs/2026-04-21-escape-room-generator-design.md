# 密室逃脫題目發想器 — 設計規格

**日期**：2026-04-21  
**狀態**：已確認

---

## 概述

一個純本地的 Python tkinter GUI 工具，讓老師與學生無需 AI API，即可透過預設範本快速發想密室逃脫謎題，並匯出成 Word 文件。

---

## 使用者

- 國中／高中國文老師（備課、設計遊戲化學習活動）
- 學生（發想自己的密室逃脫關卡）

---

## 核心功能

### 模式選擇
- **單一謎題**：生成一個謎題
- **完整遊戲**：生成故事背景 + 3～5 個串接關卡

### 主題來源
- **課文選單**（下拉）：木蘭詩、岳陽樓記、桃花源記、出師表、愛蓮說（可擴充）
  - 每篇課文預設 3～5 個關鍵詞（如木蘭詩：花木蘭、從軍、替父）
- **自訂主題**（文字輸入）：使用者自由輸入主題名稱，程式以主題名稱本身作為關鍵詞填入範本

### 謎題類型（可多選）
1. 字謎
2. 數字謎
3. 密碼謎
4. 邏輯推理謎
5. 圖像描述謎

---

## 範本系統

每種謎題類型預設 5～10 個範本，含佔位符（`{主題}`、`{關鍵詞}`、`{角色}`、`{數字}` 等）。生成時隨機抽取範本，填入使用者輸入的主題關鍵字。

**範本示例：**

| 類型 | 範本 |
|------|------|
| 字謎 | 「{主題}中有一個字，拆開來是＿＿，合起來是＿＿，答案是？」 |
| 數字謎 | 「{主題}裡共有幾個「{關鍵詞}」？數對了才能開門。」 |
| 密碼謎 | 「將「{主題}」的第 {N} 個字轉成注音，取聲母，組合出密碼。」 |
| 邏輯推理 | 「{角色A}說了謊，{角色B}說了實話，根據{情境}，誰拿到了鑰匙？」 |
| 圖像描述 | 「畫面中藏著與「{主題}」相關的物件，找出三樣東西。」 |

**完整遊戲額外生成：**
- 故事背景（1 段，從預設故事背景範本隨機選取並填入主題）
- 關卡間串接邏輯：每關末尾附「下一關提示語」範本，將下一關的謎題類型名稱填入（例如「找到數字謎的答案，才能打開下一道門」）

## 介面規格

依 CLAUDE.md 的 tkinter 標準規格：

```
┌─────────────────────────────────┐
│  密室逃脫題目發想器 v1.0         │
│  快速生成課堂密室逃脫謎題         │
├─────────────────────────────────┤
│ [模式選擇]  ○單一謎題  ○完整遊戲 │
├─────────────────────────────────┤
│ [主題設定]                       │
│  ○課文：[下拉選單 ▼]            │
│  ○自訂：[_______________]       │
├─────────────────────────────────┤
│ [謎題類型]（可多選）             │
│  ☑字謎 ☑數字謎 ☐密碼謎          │
│  ☐邏輯推理 ☐圖像描述            │
├─────────────────────────────────┤
│      [ 開始發想 ]（綠色按鈕）    │
├─────────────────────────────────┤
│ 結果預覽區（深色 ScrolledText）  │
├─────────────────────────────────┤
│  [重新發想]（灰）  [匯出Word]（藍）│
└─────────────────────────────────┘
```

**色彩**：依 CLAUDE.md 色彩系統（背景 `#f0f4f8`、卡片 `#ffffff`、執行按鈕 `#16a34a`、主要按鈕 `#2563eb`）  
**字型**：微軟正黑體

---

## Word 輸出格式

- 封面：遊戲標題 + 主題名稱
- 每個關卡獨立一頁或一區塊
  - 關卡編號與標題
  - 謎題描述
  - 提示（可選顯示）
  - 答案（可選顯示）
- 使用 `python-docx` 生成，中文字體修主題 XML 避免 MS Mincho
