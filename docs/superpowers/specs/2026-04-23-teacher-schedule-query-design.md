# 教師課表查詢系統 — 設計文件

**日期：** 2026-04-23  
**專案：** 北興國中代課管理工具  
**版本：** v1.0

---

## 1. 需求摘要

一套 tkinter GUI 工具，讓行政人員：
1. 選擇請假教師 + 星期（單日或多日）
2. 預覽該教師在選定星期的所有課（節次、科目、班級、是否兼課）
3. 一鍵將結果寫入 `114學年代課.xlsx` 的【總表】分頁（每節一行，兼課列標淡藍底色）

---

## 2. 輸入來源

| 檔案 | 用途 |
|------|------|
| `520師課表.pdf` | 主課表，209 頁，每頁一位教師 |
| `114學年代課.xlsx` | 公版代課單，工作表1 提供教師→科別對照，總表為輸出目的地 |

---

## 3. 整體架構

```
520師課表.pdf
      ↓ (首次啟動 or 手動重新載入)
  parser.py
      ↓
  課表快取.json          114學年代課.xlsx（工作表1）
      ↓                        ↓
      └──────── scheduler_gui.py ───┘
                    ↓
            excel_writer.py
                    ↓
            114學年代課.xlsx（總表 — 新增列）
```

### 模組職責

| 模組 | 職責 |
|------|------|
| `parser.py` | 解析 PDF → 輸出 `課表快取.json` |
| `scheduler_gui.py` | tkinter 主介面，協調查詢與匯出 |
| `excel_writer.py` | 寫入總表、套用淡藍底色 |
| `開啟課表查詢器.bat` | 雙擊啟動入口 |

---

## 4. PDF 解析策略

- 工具：`pdfplumber`，使用 `page.extract_tables()` 保留欄位對應
- 每頁第一行取教師姓名（格式：`101 江昆峰 202導師 ...`）
- 表格欄對應：星期一～五各一欄，列對應節次 0～8
- **兼課判斷**：班級欄位含「兼」字 → `兼課: true`
- **科別來源**：讀 工作表1，每行第一格 `_01國文` → 後續欄位為該科教師名單，建立 `{姓名: 科別}` 對照表
- 快取：解析完成後存 `課表快取.json`；下次啟動若檔案存在直接讀取，跳過解析

### JSON 快取格式

```json
{
  "江昆峰": {
    "科別": "國文",
    "schedule": {
      "一": [
        {"節次": 2, "科目": "本土語言", "班級": "204", "兼課": false},
        {"節次": 7, "科目": "國文", "班級": "202", "兼課": true}
      ],
      "三": [
        {"節次": 2, "科目": "國文", "班級": "202", "兼課": false}
      ]
    }
  }
}
```

## 6. Excel 輸出規格

**目標分頁：** 總表  
**寫入位置：** 從現有資料最後一筆的下一空白列往下新增，不覆蓋舊資料

### 欄位對應

| 欄 | 總表欄位 | 填入值 |
|----|----------|--------|
| A | 科別（請假） | 從 JSON 查教師科別 |
| B | 請假教師 | 選取的教師姓名 |
| C | 科別（代課） | 空白 |
| D | 代課教師 | 空白 |
| E | 日期 | 空白 |
| F | 星期 | 一／二／三／四／五 |
| G | 節次 | 數字 |
| H | 科目 | 課表上的科目名稱 |
| I | 班級 | 班級號碼 |
| J | 假別 | 空白 |

**兼課底色：** 若該節 `兼課: true`，整列儲存格填 `#BDD7EE`（使用 openpyxl `PatternFill`）

## 8. 邊界情況

- **第 0 節**（選手培訓等）：納入，科目欄填實際內容
- **第 8 節**：納入
- **班會**：納入，科目填「班會」
- **空白格**（無課）：跳過，不寫入
- **PDF 解析失敗**：記錄區顯示錯誤，提示手動確認該頁
- **重複寫入防呆**：同一教師同一星期若已有資料，警告後詢問是否繼續
