# 《木蘭傳》像素闖關遊戲 — 設計規格

**日期**：2026-04-21
**使用對象**：piliwu（國中國文教師）
**目標受眾**：國中生
**部署方式**：Firebase Hosting + Firebase Realtime Database

---

## 1. 遊戲概念

以《木蘭詩》為題材的課堂打怪闖關遊戲。
老師將遊戲投影到大螢幕，學生分組後用手機掃 QR Code 加入，透過回答木蘭詩相關題目對怪獸造成傷害。答對率越高、傷害越大；全組共同作戰，最終看哪組存活且累積傷害最多。

---

## 2. 關卡結構

照《木蘭詩》故事順序分 5 關，每關一隻怪獸，每關 5 題：

| 關卡 | 故事段落 | 怪獸名稱 | 怪獸 HP |
|------|----------|----------|---------|
| 第 1 關 | 從軍報名 | 刁難徵兵官 | 500 |
| 第 2 關 | 沙場征戰 | 敵軍大將「燕然」 | 800 |
| 第 3 關 | 凱旋班師 | 搶功奸臣 | 600 |
| 第 4 關 | 辭官不受 | 誘惑魔王 | 700 |
| 第 5 關 | 還我女兒身 | 最終 Boss：可汗 | 1200 |

---

## 3. 遊戲流程

```
老師開啟 teacher.html（投影）
    ↓
學生掃 QR Code → 進入 student.html → 選擇組別
    ↓
老師按「開始投票」→ 題目顯示在大螢幕與手機
    ↓
學生限時 30 秒內選答案送出（每人只能投一票）
    ↓
時間到 → Firebase 統計各組答對人數
    ↓
計算傷害：(答對人數 / 組員人數) × 100 = 本題傷害
    ↓
怪獸 HP 扣血 + 顯示各組傷害數字
    ↓
重複直到 5 題全出完 → 怪獸倒地或殘血 → 進入下一關
    ↓
5 關全過 → 勝利畫面 + 各組積分排名
```

---

## 4. 傷害與計分規則

- **本題傷害** = `Math.round(答對率 × 100)`
  - 答對率 = 本題答對票數 / 本題總投票數（非組員總人數，避免網路斷線影響）
  - 例：10 人中 8 人投票且全答對 → 100 傷害；10 人中 8 人投票、6 人答對 → 75 傷害
- **怪獸受到的傷害** = 所有組的傷害加總平均（避免各組人數不均影響）
- **組別 HP**：各組從 100 HP 開始，每答錯一題被怪獸反擊 10 HP
  - 答對率 < 30% → 被反擊
- **勝利條件**：打完 5 關，HP 最高的組獲勝

## 5. 頁面規格

### 5-1. teacher.html（老師大螢幕）

**版面**：左側主競技場 + 右側控制面板

| 區域 | 內容 |
|------|------|
| 頂部 header | 遊戲標題、第幾關/共幾關、故事段落名稱、第幾題 |
| 競技場（左） | 像素風怪獸動畫、怪獸 HP 條、各組像素英雄角色 |
| 題目區（左下） | 題目文字框，字型加大清楚投影 |
| QR Code（右） | 即時產生，學生掃碼加入 |
| 倒數計時（右） | 大字數字 + 進度條，時間到自動停止投票 |
| 各組血量（右） | 每組彩色 HP 條 |
| 即時票數（右） | 各選項票數長條圖（投票中顯示，答案公布前不顯示正解） |
| 控制按鈕（底部） | 開始投票 / 停止投票 / 公布答案 / 下一題 / 下一關 |

### 5-2. student.html（學生手機）

**流程**：進入 → 選組別 → 等待題目 → 作答 → 等待結果

| 狀態 | 畫面內容 |
|------|----------|
| 選組別 | 顯示可用組別按鈕（A/B/C 組） |
| 等待中 | 顯示組別、HP、「等待老師出題...」 |
| 作答中 | 題目 + 選項按鈕 + 倒數計時 + 送出鈕 |
| 已送出 | 「等待老師公布答案 ⏳」 |
| 答案公布 | 正確答案高亮、本組造成傷害顯示 |

- 每人每題只能投一票（localStorage 記錄）
- 組別選定後本場遊戲不能換組

### 5-3. admin.html（老師控制台）

與 teacher.html 分開的精簡操控介面，可在同一台電腦開另一個分頁：

- 選擇關卡 / 題目
- 開始 / 停止投票
- 公布答案
- 重置遊戲
- 編輯題目（可擴充）

## 8. 視覺規格

**整體風格**：像素風（Pixel Art），復古遊戲感

| 元素 | 規格 |
|------|------|
| 主色調 | 深藍背景 `#1a1a2e`、紅色強調 `#e94560` |
| 字型 | 標題：Press Start 2P（英文）、內文：微軟正黑體（中文） |
| 怪獸 | Canvas 繪製像素圖，每關不同造型 |
| 英雄 | 各組一個像素小角色，顏色不同 |
| 動畫 | 怪獸受擊晃動、HP 條流暢扣血、傷害數字彈出 |

## 9. 技術規格

| 項目 | 選擇 |
|------|------|
| 前端 | 純 HTML + CSS + JavaScript（無框架） |
| 即時同步 | Firebase Realtime Database |
| 部署 | Firebase Hosting |
| 身份識別 | Firebase Anonymous Auth（學生不需登入） |
| QR Code | qrcode.js 函式庫動態產生 |
| 像素動畫 | HTML5 Canvas |

---

## 10. 部署流程（簡要）

1. 建立 Firebase 專案
2. 啟用 Realtime Database、Hosting、Anonymous Auth
3. 將 HTML 檔案部署到 Firebase Hosting
4. 取得網址，teacher.html 自動產生 QR Code 供學生掃碼
