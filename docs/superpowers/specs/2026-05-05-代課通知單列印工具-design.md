# 代課通知單列印工具 — 設計文件

**日期**：2026-05-05  
**狀態**：已核准，待實作

---

## 問題描述

學校行政人員每週需將代課記錄依「請假教師」、「代課教師」、「班級」分別列印通知單。現有流程需手動在 Excel 中選取各老師/班級的行列再設定列印範圍，記錄多時耗時費力。

---

## 解決方案

Python tkinter GUI 工具，從現有 Excel 總表讀取資料，一鍵輸出三份 PDF（每位老師/班各佔一頁），直接開啟預覽後批次列印。

---

## 資料來源

**檔案**：`114學年代課總表-第2學期-new.xlsx`（或任意選擇的同格式 Excel）

**工作表**：`總表`

**欄位對應**（0-indexed）：

| 欄 | 內容 |
|----|------|
| 0 | 科別（請假方） |
| 1 | 請假教師 |
| 2 | 科別（代課方） |
| 3 | 代課教師 |
| 4 | 日期 |
| 5 | 星期 |
| 6 | 節次 |
| 7 | 科目 |
| 8 | 班級 |
| 9 | 假別 |
| 10 | 取消標記（值為「取消」時略過） |

**資料起始行**：第 3 行（index 2，前兩行為標題與表頭）

---

## 資料處理邏輯

1. 讀取總表，跳過前 2 行（標題 + 表頭）
2. **排除**欄 10 值為「取消」的記錄
3. 依使用者選擇的日期範圍篩選欄 4（日期）
4. 分三路分組：
   - 請假教師（欄 1）→ 請假教師通知單
   - 代課教師（欄 3）→ 代課教師通知單
   - 班級（欄 8）→ 班級代課通知單
5. 每組內依「日期 → 節次」升冪排序

---

## PDF 格式規格

### 三種通知單差異

| 通知單類型 | 標題 | 副標 | 加粗欄位 | 分組依據 |
|-----------|------|------|---------|---------|
| 請假教師 | 請假老師課務移交通知單 | 無 | 請假教師 | 請假教師 |
| 代課教師 | 代課教師通知單 | 因為任課老師請假，特請您協助代課。 | 代課教師 | 代課教師 |
| 班級 | 班級代課通知單 | 無 | 班級 | 班級 |

### 每頁版面

- 頁面：A4 直式
- 大標題：置中，粗體，18pt
- 副標（如有）：置中，10pt，灰色
- 表頭：深藍底（#1e3a5f）白字，粗體
- 資料列：奇數行淺藍底（#dce6f1），偶數行白底（#ffffff），交替增加可讀性
- 頁尾：靠左「共 N 節」、靠右「列印日期：YYYY/MM/DD」
- 每個人/班換頁

### 欄位顯示（PDF 中不顯示「科別」欄）

請假教師：請假教師、代課教師、日期、星期、節次、科目、班級、假別  
代課教師：請假教師、代課教師、日期、星期、節次、科目、班級、假別  
班級：請假教師、代課教師、日期、星期、節次、科目、班級、假別

## GUI 規格

### 視窗

- 標題：`代課通知單列印工具 v1.0`
- 寬度：520px，固定（`resizable(False, False)`）
- 背景：`#f0f4f8`

### 卡片區塊（由上至下）

1. **來源檔案**：`filedialog.askopenfilename()`，顯示路徑，預設帶入上次路徑
2. **列印週次**：起始日期 + 結束日期（Entry 輸入），快捷按鈕「本週」「上週」自動填入
3. **輸出資料夾**：`filedialog.askdirectory()`，預設與 Excel 同資料夾
4. **輸出項目**：三個 Checkbutton（請假教師 / 代課教師 / 班級通知），預設全勾

### 執行流程

- 點「產生 PDF」→ 背景執行緒處理（避免 GUI 凍結）
- 進度條：determinate，依三份 PDF 分段推進
- 執行記錄：ScrolledText 深色背景，即時顯示各步驟狀態
- 完成後：顯示「✅ 已產生 X 份 PDF，儲存於 [路徑]」，並詢問是否立刻開啟資料夾

### 日期快捷邏輯

- **本週**：本週一 ～ 本週五（依台北時間 `Asia/Taipei`）
- **上週**：上週一 ～ 上週五

---

## 輸出檔名

格式：`{通知單類型}_{起始日期}-{結束日期}.pdf`

範例：
- `請假教師通知單_0505-0509.pdf`
- `代課教師通知單_0505-0509.pdf`
- `班級代課通知單_0505-0509.pdf`

---

## 邊界情況

- 選取週次無任何資料 → 顯示警告訊息，不產生 PDF
- 某種通知單無資料（例如該週無班級記錄）→ 跳過該份 PDF，log 顯示說明
- Excel 欄位結構不符 → 啟動時偵測，提示使用者確認欄位
